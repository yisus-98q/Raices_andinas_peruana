Revisa que ninguna se vea rara antes de presentar. Se regeneran con node gen-imagenes.mjs.

¿Prefieres fotos reales? No hay que tocar el código. En la tabla productos, la columna imagen acepta cualquier URL: UPDATE productos SET imagen = 'https://…/maca.jpg' WHERE sku = 'MAC-001';
Si esa URL falla (sin internet, enlace roto), la tarjeta cae sola al emoji en vez de mostrar un cuadro gris. Por eso la demo aguanta sin conexión.
